# ADR-002 N01-N07 只作误报回归尺子，不作训练增强

- **日期**：2026-08-29 ｜ **状态**：已接受（上游 plan0829/06 §4 已拍板，此处留档）
- **背景**：官方 77 条合理工况（13_normal_context.csv）是唯一官方背书的"看似异常实为合理"样本；ML 训练管线（P1-9）引入后存在把它当负样本增强语料的诱惑。
- **选项**：
  1. 既作误报回归集也入训练集
  2. 只作误报回归尺子（validation 层资产）
  3. 完全不用
- **理由**：选项 2 保留其官方定位（"已确认属于合理运行工况"反例库），防止训练分布被官方数据污染，误报率指标因而可信、可冻结、可横向比较；选项 1 会让"误报不升"门禁失去意义（用尺子改了答卷）。
- **被否方案**：选项 1（自我裁判循环）、选项 3（浪费官方资产）。
- **后果**：`validation/normal-context-regression.mjs` 是 validation 层资产；基线冻结后"误报不升"是算法改动一票否决项。
