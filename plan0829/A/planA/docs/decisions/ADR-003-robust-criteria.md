# ADR-003 去签名带三级鲁棒判据 + 逐类独立 commit 门禁

- **日期**：2026-08-29 ｜ **状态**：已接受（上游 02§2 拍板，此处留档）
- **背景**：C03 400kW±1kW、C05 ±300±1kW 带、C06 冻结 TRAIN 标记（ELZ2=50% 份额）均为 TRAIN 经验拟合；测试集无标签无法自查。
- **选项**：
  1. 保留签名带，仅靠 ML 补偿
  2. 三级鲁棒判据替换（相对容差 → 滑窗分位带 → 因果门保留强化），逐类独立 commit
  3. 一次性大改全部类别
- **理由**：选项 2 把改动切到"每步可验证、可单独回退"的粒度；每步四重门禁（F1 降幅≤0.012 / FN≤1 / N01-N07 不升 / 哨兵绿）保证不会比现状差；选项 3 在测试集无标签条件下风险不可控。
- **被否方案**：选项 1（过拟合敞口原样保留）、选项 3（单步风险过大）。
- **后果**：每个 commit 附「改动前后四项指标对照表」入校准记录块；C06 的 TRAIN 标记以"滑窗份额带"替代后，需在公开 TRAIN 40 事件上复验全命中。
